# ML Launchpad - Groq Chatbot

An AI chatbot project developed using Python, Groq API, GPT-OSS-20B, and Gradio.

## Technologies Used

- Python
- Groq API
- GPT-OSS-20B
- Gradio
- Google Colab
- Jupyter Notebook

## Features

- AI chatbot using Groq API
- GPT-OSS-20B model integration
- Interactive chatbot interface
- Model selection using dropdown

## How to Run

1. Open the notebook in Google Colab.
2. Install the required Python packages.
3. Add your Groq API key as an environment variable.
4. Run the notebook cells from top to bottom.

## API Key

For security, the API key is not included in this repository.
